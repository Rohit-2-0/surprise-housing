# 🏠 Surprise Housing Price Prediction

This project involves predicting housing prices using regression models. It walks through data loading, exploratory data analysis (EDA), feature engineering, and applying multiple regression techniques to build an accurate predictive model.

## 📂 Files

- **`Surprise_Housing(2).ipynb`** – Main Jupyter notebook containing the full pipeline from EDA to model evaluation.
- **`housing.csv`** *(assumed)* – Dataset with house-related features used for training and testing the models.

## 🔍 Features

- Load and explore housing data
- Visualize feature distributions and relationships
- Preprocess features (handle missing values, encode categoricals, etc.)
- Train multiple regression models:
  - Linear Regression
  - Ridge Regression
  - Lasso Regression
- Use GridSearchCV for hyperparameter tuning
- Evaluate models using regression metrics (R², MSE, MAE, AIC, BIC, etc.)

## 🧰 Libraries Used

- `numpy`, `pandas`
- `matplotlib`, `seaborn`
- `scikit-learn`
- `RegscorePy` for advanced regression metrics
